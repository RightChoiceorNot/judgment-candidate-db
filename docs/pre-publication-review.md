# 公開發布前審查草案

審查日期：2026-09-10。此文件是發布計畫與風險盤點，不授權部署、開放讀取或公開個人資料。

## 現況結論

系統目前僅供內部處理。所有候選人、裁判索引與覆核資料表皆啟用 RLS，沒有 anon 或 authenticated 的公開讀取 policy。前端原型是靜態 fixture，沒有資料庫或環境變數連線。原始 JFULL 只存於被 Git 忽略的本機 `storage/`。

## 擬公開欄位與風險

| 欄位或資料 | 目前狀態 | 主要風險 | 發布前必要條件 |
| --- | --- | --- | --- |
| 候選人姓名、選區、政黨 | 不公開 | 同名誤認、選舉資格或名單異動 | 僅採正式選舉公報或審定名冊，保留來源與日期 |
| 裁判書外部 JID、法院、日期、案號 | 不公開 | 可連結個人並被誤讀為不利指控 | 人工確認身分、案件結果、確定與撤除狀態 |
| 姓名比對理由、別名、JFULL 定位 | 不公開 | 直接揭露未確認個資與原始全文位置 | 保持內部稽核用途，不納入公開 API 或頁面 |
| 覆核結論與證據來源 | 不公開 | 判斷品質、法律與隱私風險 | 明確覆核標準、第二人審查、可追溯事件紀錄 |
| 撤除狀態與更新紀錄 | 不公開 | 舊資料持續顯示 | 每次發布前再次精確 JID 對帳並停用撤除紀錄 |

## 公開資料政策與免責文字草案

本系統整理公開來源中的裁判資訊，目的在支持人工、脈絡化的公共資訊查核。裁判書不等於前科、犯罪事實或候選人資格判斷；姓名或文字命中也不表示同一人。本系統不公開未完成人工覆核的個人資料，並保留來源、更新與撤除紀錄。若來源撤除、身分未能確認，或案件結果與確定狀態不足以支持呈現，資料不得公開。

## 發布前檢查清單

1. 逐表確認 RLS 與 anon/authenticated 權限，禁止以 service role 供前端使用。
2. 檢查前端建置產物、環境變數與 API 端點，不得含 service-role key、JFULL 或未覆核個資。
3. 掃描 Git 工作樹與完整歷史，確認沒有原始資料、秘密或未覆核資料。
4. 對每筆擬公開紀錄確認身分、案件結果、確定狀態、撤除狀態及人工覆核事件。
5. 完成公開欄位清冊、資料更正與撤除申訴管道，以及發布責任人核准。
6. 在獨立的正式核准後，才可建立最小化的公開資料集、API 與部署計畫。

## 不可自動化的判斷

任何姓名命中、別名命中、選舉資料更新或裁判文字摘錄都不能自動成為公開指控。涉及身分、負面影響或法律風險的呈現，一律須在上述條件完整後由人員審核。
